# Utility Scripts
[![standard-readme compliant](https://img.shields.io/badge/readme%20style-standard-brightgreen.svg)](https://github.com/RichardLitt/standard-readme)

This is just a collection of scripts to help with various processes. Most are designed around use in a monitoring system environment such as Nagios or a Nagios-like type product. 

## Install

Scripts in this directory are a mix of Powershell, Bash, Python, and maybe others. Each should include information in the top of the file regarding any additional libraries that need to be installed for use. 

## Usage

Individual scripts should each include an example for how to run them and what the expected output will be. For most examples you can expect the following: 

1. Run on the command line or via monitoring tool
2. Several command line arguments
3. Output includes a status code (0=OK, 1=Warning, 2=Critical, 3=Unknown)
4. Output includes a status or error message
